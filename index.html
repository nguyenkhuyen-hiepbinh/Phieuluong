Hướng dẫn cài đặt (làm 1 lần, khoảng 30 phút)

Tất cả miễn phí. Nên dùng một tài khoản Gmail riêng để gửi lương.

A. Đưa trang web lên GitHub Pages

  1. Vào github.com, tạo tài khoản miễn phí.
  2. Bấm + → New repository. Đặt tên phieu-luong, chọn Public, bấm Create repository.
  3. Bấm uploading an existing file, kéo file index.html vào, bấm Commit changes.
  4. Vào Settings → Pages. Ở mục Branch chọn main và /(root) → Save.
  5. Chờ 1–2 phút, trang sẽ có địa chỉ https://tên-github.github.io/phieu-luong/.

Trang công khai nhưng không chứa dữ liệu lương nào. File Excel chỉ được đọc trên máy người dùng.

B. Tạo Google Client ID

  1. Vào console.cloud.google.com bằng Gmail dùng để gửi lương. Tạo dự án mới tên Phieu luong.
  2. Tìm Gmail API ở ô tìm kiếm → bấm Enable (Bật).
  3. Vào Google Auth Platform (hoặc OAuth consent screen) → Get started: điền tên ứng dụng, email hỗ trợ, chọn External.
  4. Mục Audience → Test users → thêm chính Gmail gửi lương.
  5. Mục Clients → Create client → loại Web application. Ở Authorized JavaScript origins dán địa chỉ https://tên-github.github.io (không có đuôi /phieu-luong).
  6. Bấm Create, chép Client ID (đuôi .apps.googleusercontent.com) dán vào Bước 1.

Giao diện Google Cloud thỉnh thoảng đổi tên menu; nếu không thấy đúng tên, tìm mục có ý nghĩa tương tự.

C. Lần đăng nhập đầu tiên

  1. Mở trang GitHub Pages, bấm Đăng nhập Google.
  2. Google báo "Google chưa xác minh ứng dụng này" → bấm Tiếp tục. Đây là bình thường với ứng dụng nội bộ.
  3. Nhớ tick ô cho phép "Gửi email thay mặt bạn", nếu không sẽ không gửi được.

D. Mỗi tháng

  1. Bước 1: đổi Kỳ lương.
  2. Bước 2: tải file Excel tháng mới (cột được nhớ từ lần trước).
  3. Bước 3: xem lỗi, mở vài phiếu kiểm tra.
  4. Bước 4: gửi thử → gửi hàng loạt → tải báo cáo lưu lại.

Trong lúc gửi, giữ tab mở. Nếu bị gián đoạn, mở lại và bấm gửi tiếp: người đã nhận sẽ tự được bỏ qua (trên cùng trình duyệt).
