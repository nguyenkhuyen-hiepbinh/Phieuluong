Hướng dẫn cài đặt

Làm một lần, khoảng 20 phút, tất cả miễn phí. Nên dùng một tài khoản Gmail riêng để gửi lương.

A. Trang web

  1. Trang đang chạy tại https://phieuluong-nk.onrender.com (Render, miễn phí).
  2. Mã nguồn nằm trong kho GitHub Phieuluong. Mỗi lần kho được cập nhật, Render tự đưa bản mới lên sau khoảng 20 giây.
  3. Thư mục lib/ chứa sẵn các thư viện, trang không phụ thuộc CDN bên ngoài.

Trang công khai nhưng không chứa dữ liệu lương. File Excel chỉ được đọc trên máy người dùng.

B. Tạo Google Client ID

  1. Vào console.cloud.google.com bằng Gmail dùng để gửi lương. Tạo dự án mới tên Phieu luong.
  2. Tìm Gmail API → bấm Enable (Bật).
  3. Vào Google Auth Platform → Get started: điền tên ứng dụng, email hỗ trợ, chọn External.
  4. Audience → Test users → thêm chính Gmail gửi lương.
  5. Clients → Create client → loại Web application. Ở Authorized JavaScript origins dán địa chỉ ở tab Kết nối Gmail (không có dấu / ở cuối).
  6. Bấm Create, chép Client ID dán vào tab Kết nối Gmail.

C. Lần đăng nhập đầu tiên

  1. Bấm Đăng nhập Google ở góc trên.
  2. Google báo "chưa xác minh ứng dụng" → bấm Tiếp tục.
  3. Tick ô "Gửi email thay mặt bạn", nếu không sẽ không gửi được.

D. Mỗi tháng

  1. Bước 1: đổi Kỳ lương.
  2. Bước 2: tải file Excel tháng mới (cột được nhớ từ lần trước).
  3. Bước 3: xem lỗi, mở vài phiếu kiểm tra.
  4. Bước 4: gửi thử → gửi hàng loạt → tải báo cáo lưu lại.
